v7.7.23 적용 방법

1. 현재 검은색 PC 수집기 창을 닫습니다.
2. ZIP을 새 폴더에 압축 해제합니다.
3. GitHub Desktop에서 alldaypick-order-alert 저장소를 선택합니다.
4. Repository → Show in Explorer로 기존 프로젝트 폴더를 엽니다.
5. 압축 해제한 폴더의 내용을 기존 프로젝트 폴더에 모두 복사하고 덮어씁니다.
6. .git, backend\.env.local, backend\firebase-service-account.json은 기존 파일을 유지합니다.
7. GitHub Desktop Summary: v7.7.23 최신 텔레그램 썸네일 강제갱신
8. Commit to main → Push origin을 누릅니다.
9. Render 배포 완료를 확인합니다.
10. START_AGENT.cmd를 실행합니다.
11. 시작 문구: Starting ALLDAYPICK order agent v7.7.23 FRESH THUMBNAIL REFRESH...
12. 웹앱을 Ctrl+F5로 새로고침합니다.
13. 다음 실제 주문·CS 알림에서 변경된 대표사진이 오는지 확인합니다.
