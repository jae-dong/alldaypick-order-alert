[v7.7.35 데일리픽 운영]

현재 기본 운영은 데일리픽만 ON, 올데이픽은 OFF입니다.
.env.local의 데일리픽 스마트스토어/11번가/롯데온 API 값은 그대로 유지하세요.

현재 권장값:
ORDER_ALERT_BUSINESS_PROFILE=DAILYPICK
ALLDAYPICK_PROFILE_ENABLED=0
DAILYPICK_PROFILE_ENABLED=1

나중에 올데이픽을 다시 사용할 때:
ALLDAYPICK_PROFILE_ENABLED=1
ORDER_ALERT_BUSINESS_PROFILE=ALLDAYPICK
으로 변경 후 수집기를 재시작하면 됩니다.

G마켓/옥션은 ESM API 승인 전까지 미연동입니다.
