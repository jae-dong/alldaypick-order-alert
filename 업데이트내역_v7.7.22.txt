v7.7.23 최신 썸네일 강제갱신·교환완료 정리·전체통계

1. 쿠팡 교환 API 조회 방식을 변경했습니다.
- RECEIPT/PROGRESS만 따로 조회하지 않고 status를 생략하여 전체 상태를 조회합니다.
- 동일 exchangeId가 여러 상태로 잡히면 modifiedAt이 가장 최신인 행을 사용합니다.
- 시간이 같으면 SUCCESS/REJECT/CANCEL 같은 종료 상태를 우선합니다.

2. 2026-07-26 00:55(KST) 교환 0건 기준선을 적용했습니다.
- 사용자가 판매자센터에서 쿠팡·스마트스토어 실제 미처리 교환 0건을 확인한 시각을 기준으로 합니다.
- 기준선 이전 교환 문서는 API가 오래된 PROGRESS 값을 반환하더라도 완료로 정리합니다.
- 기준선 이후 새로 접수되는 교환은 정상적으로 신규 교환요청에 표시됩니다.

3. Firestore에 남은 이전 교환 문서를 시작 시 직접 정리합니다.
- 쿠팡과 스마트스토어 activeState=true 교환 문서를 검사합니다.
- 기준선 이전 문서는 activeState=false, 교환완료로 변경합니다.
- 로컬 Firestore 미러 캐시도 초기화하여 완료 교환이 다시 살아나는 현상을 막습니다.

4. 스마트스토어 legacy 교환 객체 처리 방식을 보강했습니다.
- currentClaim이 아닌 오래된 exchange 객체는 기준선 이전이거나 상태가 불명확하면 미처리로 세지 않습니다.
- 기준선 이후 currentClaim으로 확인되는 새 교환만 정상 표시합니다.

5. 기존 기능 유지
- 당일 상품주문 원장, 전체 상품 통계, 기간 전체 통계
- 신규·취소·반품·교환·문의 텔레그램 알림과 상품 썸네일
- 스마트스토어 선물하기 미수락 제외
- G마켓·옥션 API 승인 전 집계 제외
