v7.7.21 적용 방법

1. 실행 중인 검은색 PC 수집기 창을 닫습니다.
2. ZIP을 새 폴더에 압축 해제합니다.
3. GitHub Desktop에서 alldaypick-order-alert 저장소를 선택합니다.
4. Repository > Show in Explorer로 실제 프로젝트 폴더를 엽니다.
5. 압축 해제한 내용물을 모두 복사해 덮어씁니다.
6. .git, backend\.env.local, backend\firebase-service-account.json은 기존 파일을 유지합니다.
7. Summary: v7.7.21 교환 0건 강제동기화
8. Commit to main 후 Push origin을 누릅니다.
9. Render 배포 성공을 확인합니다.
10. START_AGENT.cmd를 실행합니다.
11. 웹앱에서 Ctrl+F5로 강력 새로고침합니다.
12. 지금 수집을 누르면 교환 처리상태 확인이 끝난 뒤 완료됩니다.
