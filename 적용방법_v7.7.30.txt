v7.7.30 적용 방법

1. 실행 중인 START_AGENT 검은 창을 닫습니다.
2. 압축파일을 새 폴더에 풉니다.
3. GitHub Desktop에서 alldaypick-order-alert 저장소를 선택합니다.
4. Repository > Show in Explorer를 눌러 기존 프로젝트 폴더를 엽니다.
5. 압축을 푼 파일을 기존 프로젝트 폴더에 모두 복사하고 덮어씁니다.
6. .git, backend\.env.local, backend\firebase-service-account.json은 기존 파일을 유지합니다.
7. GitHub Desktop Summary: v7.7.30 빠른 스크롤·쇼핑몰 바로처리
8. Commit to main > Push origin을 누릅니다.
9. Render 배포 성공을 확인합니다.
10. START_AGENT.cmd를 다시 실행합니다.
11. 웹앱에서 Ctrl+F5 또는 주소 끝에 ?v=7.7.30을 붙여 새로고침합니다.
12. 상품명이나 쇼핑몰 처리 버튼을 누르면 판매자센터가 열리고 조회번호가 복사되는지 확인합니다.
