v7.7.21 배포 전 검증 결과

수정 원인
- 처리완료 요청이 Firestore에서 activeState=false로 바뀌어도 웹 화면이 activeState를 확인하지 않아 교환요청 숫자에 계속 남는 오류를 확인했습니다.
- 즉시수집 버튼이 쿠팡 교환 조회가 끝나기 전에 완료로 표시되는 구조도 확인했습니다.

반영 내용
- 웹 화면은 activeState=false인 취소·반품·교환·문의를 즉시 완료 처리하고 진행 목록에서 제외합니다.
- API 목록 대조로 종료된 요청은 activeState뿐 아니라 status/statusLabel도 완료 상태로 저장합니다.
- 지금 수집 버튼은 쿠팡 교환 처리상태 직접 확인을 마친 뒤 완료됩니다.
- 스마트스토어 교환은 즉시수집의 상품주문 상세 대조에서 종료 정리됩니다.
- 쿠팡 직접 종료 처리 후 로컬 Firestore mirror cache도 초기화해 완료 요청이 다시 살아나는 현상을 방지합니다.
- 나머지 취소·반품·문의는 백그라운드에서 이어서 확인합니다.
