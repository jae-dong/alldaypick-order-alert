v7.7.25 적용 방법

1. 실행 중인 검은색 PC 수집기 창을 닫습니다.
2. ZIP 파일을 새 폴더에 압축 해제합니다.
3. GitHub Desktop에서 alldaypick-order-alert 저장소를 선택합니다.
4. Repository → Show in Explorer를 눌러 기존 프로젝트 폴더를 엽니다.
5. 압축 해제한 폴더 안의 모든 파일을 기존 프로젝트 폴더에 복사하고 덮어씁니다.
6. .git, backend\.env.local, backend\firebase-service-account.json은 기존 파일을 유지합니다.
7. GitHub Desktop Summary: v7.7.25 진행목록 썸네일 자동채우기
8. Commit to main → Push origin을 누릅니다.
9. Render 배포 성공을 확인합니다.
10. START_AGENT.cmd를 실행합니다.
11. 시작 문구: Starting ALLDAYPICK order agent v7.7.25 ACTIVE THUMBNAIL BACKFILL...
12. 시작 동기화 후 '진행목록 썸네일 채우기 완료' 로그가 나올 때까지 기다립니다.
13. 웹앱에서 Ctrl+F5로 강력 새로고침합니다.
14. 현재 진행 중 주문 목록에서 상품 썸네일을 확인합니다.
15. 일부 사진이 없으면 웹앱의 즉시 수집을 한 번 누르고 로그의 실패 상품을 확인합니다.
