주문알림 v7.7.35 - 데일리픽 전용 절전 / 올데이픽 OFF

기준: v7.7.34 사업자 프로필 후보에서 한 번만 수정한 최적화 후보입니다.
안정 기준본은 사용자 승인 전까지 v7.7.33입니다.

1. 올데이픽 사업자 프로필 기본 OFF
- ALLDAYPICK_PROFILE_ENABLED=0 기본
- 데일리픽은 DAILYPICK_PROFILE_ENABLED=1 기본
- 활성 기본 프로필은 DAILYPICK
- 나중에 올데이픽이 필요하면 .env.local에서 ALLDAYPICK_PROFILE_ENABLED=1 및 ORDER_ALERT_BUSINESS_PROFILE=ALLDAYPICK으로 다시 켤 수 있음

2. 데일리픽 계정만 수집
- 스마트스토어/11번가/롯데온 데일리픽 API만 실행
- 데일리픽 쿠팡은 기존처럼 OFF
- G마켓/옥션은 ESM API 승인 대기 상태로 미연동

3. Firestore 무료한도 절감
- 데일리픽 백엔드 조회는 가능한 쿼리에서 businessKey=dailypick 조건을 서버 단계에 적용
- 웹은 데일리픽 운영 시작일(2026-09-13) 이후 데이터만 구독
- 데일리픽 모드에서는 올데이픽용 과거 미완료/동기화 보조 구독을 실행하지 않음
- 통계/썸네일/일일원장 복구 조회도 데일리픽 문서 위주로 제한
- Firestore 로컬 미러 캐시도 데일리픽 전용 파일로 분리해 올데이픽 캐시와 섞이지 않게 함

4. 무료한도 초과 로그 반복 억제
- 보호 상태 진입 후 동일 건너뜀 로그를 반복 출력하지 않음

5. 실패 시 원칙
- 이 수정으로 문제가 계속되면 v7.7.35 위에 추가 패치를 계속 붙이지 않고 v7.7.33 기준 안정본으로 롤백 후 재작업
