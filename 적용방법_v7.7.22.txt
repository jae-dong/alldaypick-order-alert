v7.7.22 적용 방법

1. 현재 실행 중인 검은색 PC 수집기 창을 닫습니다.
2. ZIP 파일을 별도의 새 폴더에 압축 해제합니다.
3. GitHub Desktop에서 alldaypick-order-alert 저장소를 선택합니다.
4. Repository → Show in Explorer를 눌러 기존 프로젝트 폴더를 엽니다.
5. 압축 해제한 폴더 안의 모든 파일을 기존 프로젝트 폴더에 복사하고 모두 덮어씁니다.
6. .git, backend\.env.local, backend\firebase-service-account.json은 반드시 기존 파일을 유지합니다.
7. GitHub Desktop Summary: v7.7.22 교환완료 공식목록·기준선 정리
8. Commit to main → Push origin을 누릅니다.
9. Render 배포 성공을 확인합니다.
10. START_AGENT.cmd를 실행합니다.
11. 검은 창에서 다음 문구를 확인합니다.
    Starting ALLDAYPICK order agent v7.7.22 AUTHORITATIVE EXCHANGE CLEANUP...
    교환 0건 기준선 정리 완료: 종료 N · 기준 2026-07-26T00:55:00+09:00
12. 웹앱에서 Ctrl+F5로 강력 새로고침합니다.
13. 웹앱의 지금 수집을 한 번 누릅니다.
14. 검은 창에서 교환 공식 미처리 동기화 완료 문구를 확인합니다.
15. 실제 미처리 교환이 없으므로 웹 교환요청이 0건인지 확인합니다.
