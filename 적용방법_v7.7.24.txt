v7.7.24 적용 방법

1. 현재 실행 중인 검은색 PC 수집기 창을 닫습니다.
2. ZIP 파일을 별도의 새 폴더에 압축 해제합니다.
3. GitHub Desktop에서 alldaypick-order-alert 저장소를 선택합니다.
4. Repository → Show in Explorer를 눌러 기존 프로젝트 폴더를 엽니다.
5. 압축 해제한 폴더 안의 모든 파일을 기존 프로젝트 폴더에 복사하고 모두 덮어씁니다.
6. .git, backend\.env.local, backend\firebase-service-account.json은 기존 파일을 유지합니다.
7. GitHub Desktop Summary: v7.7.24 진행목록 썸네일·월별 엑셀통계
8. Commit to main → Push origin을 누릅니다.
9. Render 배포 성공을 확인합니다.
10. START_AGENT.cmd를 실행합니다.
11. 시작 문구: Starting ALLDAYPICK order agent v7.7.24 THUMBNAIL EXCEL STATS...
12. 검은 창은 계속 켜 둡니다.
13. 웹앱에서 Ctrl+F5로 강력 새로고침합니다.
14. 현재 진행 중 주문 목록에서 상품 썸네일을 확인합니다.
15. 주문 통계에서 기간 또는 월을 선택하고 엑셀 내려받기를 누릅니다.
